1. INÍCIO DE SESSÃO:
   Flutter → POST /sessoes → Flask → MySQL → MQTT → ESP32 → Liga Motor

2. CONTAGEM:
   Sensor → ESP32 → HTTP POST /leituras → Flask → MySQL → Flutter (atualiza UI)

3. FINALIZAÇÃO:
   Flutter → POST /sessoes/{id}/finalizar → Flask → MySQL → MQTT → ESP32 → Para Motor

├── GET  /sessoes         - Listar sessões

┌─────────────────────────────────────────────────────────────────────────────────┐
│                              COMPONENTES TÉCNICOS                              │
└─────────────────────────────────────────────────────────────────────────────────┘

FRONTEND (Flutter):
├── Framework: Flutter/Dart
├── Estado: SharedPreferences
├── HTTP: http package
├── UI: Material Design 3
└── Arquitetura: MVC

BACKEND (Flask):
├── Framework: Flask (Python)
├── CORS: Habilitado
├── Database: MySQL + SQLAlchemy
├── MQTT: paho-mqtt
└── Logging: Python logging

DISPOSITIVO (ESP32):
├── Microcontrolador: ESP32
├── Sensor: E18-D80NK (infravermelho)
├── Motor: Stepper motor
├── Comunicação: WiFi + HTTP + MQTT
└── Linguagem: Arduino C++

BANCO DE DADOS (MySQL):
├── sessoes_producao - Sessões de produção
├── leituras - Leituras do sensor
├── clientes - Clientes
├── produtos - Produtos
└── dispositivos - Dispositivos IoT
